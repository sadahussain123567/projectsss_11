Put your photos in this folder.

Default names used by data/birthday.ts:
  hero.jpg                      (the framed photo on the first screen)
  memory-1.jpg ... memory-8.jpg (the gallery)
  story-1.jpg, story-2.jpg      (the "Our Story" timeline)

Use any file names you like, just update the paths in data/birthday.ts.
Tip: .jpg / .png / .webp all work. Around 1600px on the long side is plenty.
